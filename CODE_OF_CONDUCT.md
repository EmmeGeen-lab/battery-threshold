# Code of conduct

Be respectful, constructive, and patient. Technical disagreement is welcome;
personal attacks, harassment, discrimination, and publication of another
person's private information are not.

Reports should focus on reproducible behavior and must not include laptop serial
numbers or other unique identifiers. Maintainers may edit or remove content that
violates these expectations and may restrict repeated disruptive participation.

For private conduct reports, use the contact method listed on the maintainer's
GitHub profile. A dedicated project address will be added before publication.
