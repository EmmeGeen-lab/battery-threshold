# Contributing

Contributions are welcome, especially hardware reports, translations, init
system testing, and accessibility improvements.

1. Open an issue before a large change.
2. Keep the privileged helper small and POSIX-shell compatible.
3. Never weaken input validation or make the GUI run as root.
4. Run `make check` before submitting a change.
5. Update documentation when behavior changes.

Contributions are licensed under GPL-3.0-or-later.
